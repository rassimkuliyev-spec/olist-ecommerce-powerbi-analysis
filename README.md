## Project Overview
Power BI project analyzing the Brazilian Olist e-commerce dataset for 2016–2018.

The dashboard provides an overview of sales performance, revenue, orders, delivery time, product categories, customer geography, and customer reviews.

## Dashboard

![Olist E-Commerce Sales Dashboard](Olist%20sales%20project.png)

## Key Metrics
- Total Sales: 14M
- Total Revenue: 16M
- Total Orders: 99K
- Average Delivery Time: 12.5 days

## Analysis
The dashboard explores:
- Sales trends over time
- Top product categories by sales
- Sales distribution by customer state
- Customer review score distribution
- Order and delivery performance
